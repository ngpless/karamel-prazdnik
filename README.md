# Карамель: сайт агентства детских и семейных праздников

Учебный проект (эксплуатационная практика, 38.03.05 «Бизнес-информатика»). Агентство, его адрес, телефон, цены и тексты вымышленные и помечены на сайте как учебные.

Стек: PHP 8 без фреймворков и CMS, PDO, MySQL/MariaDB (для быстрой проверки поддержан SQLite), чистый CSS, JavaScript только для меню и смены баннеров. Весь интерфейс на русском языке.

## Быстрая проверка (встроенный сервер PHP, база SQLite)

Нужен PHP 8.0 и новее с расширениями `pdo_sqlite` и `mbstring`.

```
php -S 127.0.0.1:8080 router.php
```

Откройте http://127.0.0.1:8080/. Файл `config.php` создавать не нужно: без него сайт берёт настройки из `config.example.php` (режим SQLite). База `data/karamel.sqlite` создаётся и заполняется при первом обращении. Чтобы вернуть начальное состояние, остановите сервер и удалите этот файл.

## XAMPP (Apache и MySQL/MariaDB)

Порядок проверен на XAMPP 8.2.12 (Apache 2.4.58, MariaDB 10.4.32, PHP 8.2.12).

1. В XAMPP Control Panel запустите модули **Apache** и **MySQL**.
2. Скопируйте содержимое репозитория в `htdocs\karamel` (сайт определяет свой адрес сам и работает и в корне, и в подпапке).
3. Откройте http://localhost/phpmyadmin/ и создайте базу `karamel` с сравнением `utf8mb4_unicode_ci`.
4. В базе `karamel` на вкладке «Импорт» загрузите сначала `sql/schema.sql`, затем `sql/seed.sql`. Должно получиться девять таблиц.
5. Скопируйте `config.example.php` в `config.php` и укажите:
   ```php
   'driver' => 'mysql', 'host' => 'localhost', 'port' => 3306,
   'name' => 'karamel', 'user' => 'root', 'pass' => '',
   ```
6. Откройте http://localhost/karamel/. Страница 404 работает через `.htaccess` (нужны `mod_rewrite` и `AllowOverride All`, в XAMPP они включены).

## Размещение на бесплатном хостинге (например, InfinityFree)

1. Создайте на хостинге базу MySQL и запишите имя базы, пользователя, пароль и сервер из панели.
2. Через phpMyAdmin хостинга импортируйте `sql/schema.sql` и `sql/seed.sql`.
3. Скопируйте `config.example.php` в `config.php`, впишите данные из панели и поставьте `'debug' => false`.
4. Загрузите файлы сайта в каталог `htdocs` (FTP или файловый менеджер). Файл `.htaccess` должен попасть на сервер, он отвечает за страницу 404 и закрывает служебные файлы.
5. Откройте сайт и проверьте несуществующий адрес: должна открыться страница 404.

## Учётные записи

Пароли хранятся только в виде хеша (`password_hash`). Политика: пароль от 8 знаков, буква и цифра; после 5 неверных попыток вход блокируется на 10 минут; временный пароль, выданный сотрудником, нужно сменить при первом входе.

| Роль | Логин | Пароль |
|---|---|---|
| Клиент | `client` | `Karamel-Client25` |
| Сотрудник (менеджер) | `manager` | `Karamel-Manager25` |
| Администратор | `admin` | случайный одноразовый пароль, печатается один раз при сборке начальных данных: `python tools/build_seed.py` (можно задать свой ключом `--admin-password`) |

## Структура репозитория

```
index.php about.php services.php articles.php article.php news.php search.php
contacts.php sitemap.php 404.php register.php login.php logout.php setview.php
cabinet.php messages.php request.php    страницы сайта и личный кабинет клиента
staff/   панель сотрудника: заявки, сообщения, обращения, клиенты, статьи, новости
admin/   панель администратора: пользователи и роли, баннеры
inc/     подключение, база данных, права, помощники, шапка, подвал, компоненты
assets/  css (style.css, lowvision.css), js, img (собственные SVG-иллюстрации)
sql/     schema.sql (MySQL), schema_sqlite.sql, seed.sql (начальные данные)
content/ тексты 20 статей (источник для seed.sql)
tools/   build_seed.py (сборка seed.sql), gen_svg.py (иллюстрации)
router.php  маршрутизатор встроенного сервера PHP, .htaccess  правила для Apache
```

База данных: девять таблиц (`users`, `sections`, `articles`, `news`, `services`, `banners`, `messages`, `requests`, `feedback`), схема в `sql/schema.sql`.

## Безопасность

`password_hash` и `password_verify`; подготовленные запросы PDO; экранирование всего вывода; токен CSRF во всех формах; проверка роли на каждой служебной странице; закрытые от браузера каталоги `inc`, `sql`, `data`, `content`; проверка адресов возврата после переключения стиля и входа.
